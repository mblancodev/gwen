How it works

Hold, speak, paste.

A small bar at the bottom of the screen. Your words become text where the cursor already is. Nothing leaves this Mac unless you turn on optional polish.

  • Hold ⌃

    Speak while you hold Control. The bar shows levels and a live transcript as you go.

  • Let go

    Local whisper finishes the pass. Punctuation and filler cleanup run on this Mac, then the text is pasted.

  • Or tap ⌃⇧

    Translate the selection (or a recent copy) with Apple Translation on macOS 15 and later. Pick the language on the idle bar.

On your Mac

Local by default. Free forever.

Gwen is MIT licensed. Transcription uses a local whisper.cpp server. Punctuation and formatting stay on device. Translation uses Apple's Translation framework when you ask for it.

  • No account. Clone the repo, build the HUD. Whisper installs and starts with Gwen — no manual server step.
  • Prefs stay home. Config and learned words live under ~/.gwen/.
  • Optional polish stays off. Having an agent CLI on this Mac tidy each take is a setting, not the default.
$ ./bin/gwen build
# compiles ~/.gwen/Gwen.app

$ ./bin/gwen hud
Launching Gwen HUD (⌃ dictate, ⌃⇧ translate).

$ ./bin/gwen settings
# Dictation · Language · Shortcuts · Capture
# ensures Whisper on 127.0.0.1:2022 (installs on first run)
$ ./bin/gwen listen
gwen listen: hold ⌃ to dictate, ⌃⌃ or Hey Gwen
for hands-free. Ctrl-C to quit.

# or: ./bin/gwen setup   # install/start Whisper only
$ ./bin/gwen mock bar
# scripted dictate → clean → paste

$ ./bin/gwen mock translate
$ ./bin/gwen mock punctuation
# before/after samples in the terminal

Shortcuts

A few keys. The rest is speaking.

Hold ⌃

Dictate; let go to finish. The text is pasted where the cursor is.

⌃⌃ or Hey Gwen

Dictate hands-free; it ends when you stop talking.

Tap ⌃⇧

Translate the selection, or what you copied in the last minute.

Hold ⌃, tap ⇧ twice

Translate what you say into the language on the idle chip.

Tap ⌃

Stop whatever the bar is doing: nothing is pasted or started.

One line. Any Mac.

Runs on macOS 13 and later. Translation needs macOS 15. Grant Accessibility on first run. gwen listen (and setup / hud) starts local Whisper for you. Or download the disk image (Apple silicon and Intel): it is not notarized, so macOS asks you to allow it under Privacy & Security the first time.

$ curl -fsSL https://gwen-chi.vercel.app/install.sh | sh
# clones to ~/.gwen/src, builds Gwen.app, starts it at login
